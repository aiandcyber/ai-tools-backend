# Office tools

Use `run_office_tool` with the matching `tool_id`.

## Common tool ids

- Create DOCX / XLSX / PPTX from text fields
- Convert CSV ↔ XLSX
- Merge workbooks
- Fill DOCX templates from JSON/field values

Require uploads when the tool accepts files. Keep options_json valid JSON.
